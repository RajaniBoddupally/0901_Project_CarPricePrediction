This project focuses on predicting the selling prices of used cars by using machine learning techniques. The process begins with  data preprocessing, including handling missing values, converting categorical variables, and addressing outliers. Exploratory Data Analysis (EDA) is conducted to understand the relationships between features and the target variable, `selling_price`. Key features in the dataset include mileage, engine size, fuel type, seller type, transmission type, and the car's age, derived from the manufacturing year.

Multiple machine learning models are trained, including Linear Regression, Random Forest Regressor, Gradient Boosting Regressor, and Ridge Regression. To improve accuracy, hyperparameter tuning is performed using `RandomizedSearchCV`. The performance of these models is evaluated based on metrics such as R-squared scores for both training and testing sets, as well as cross-validation scores.

This project is implemented in Python, utilizing libraries like pandas, numpy, matplotlib, seaborn, and scikit-learn. The repository provides a script that automates the entire workflow. To run the project, clone the repository, install the required dependencies, and execute the script or just download the ipynb file and run the code in google colab. The project provides valuable insights into how various features influence car prices and demonstrates effective approaches to building predictive models.
